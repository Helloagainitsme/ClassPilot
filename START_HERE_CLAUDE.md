# Start ClassPilot with Claude Code in VS Code (Windows)
1. Extract the ZIP to an ordinary local folder, e.g. C:\Projects\ClassPilot. Open the folder containing package.json, CLAUDE.md and docs in VS Code (File > Open Folder).
2. Open Terminal > New Terminal (PowerShell). Run `node --version`, `npm --version` (or `npm.cmd --version`), `git --version`. If missing, install supported Node LTS and Git from their official sites, restart VS Code. Do not add real pupil data or credentials to the folder.
3. Open the Claude Code panel or run `claude` from the VS Code terminal if installed as CLI. Use normal permissions and approve scoped project edits/commands as appropriate. Paste the entire contents of START_WITH_CLAUDE.txt. The detailed requirements are in docs/MASTER_DEVELOPMENT_PROMPT.md, and CLAUDE.md carries persistent rules. Do not paste the huge master document into each turn. Previous Codex docs remain reference material; new master wins conflicts.
4. Let Claude inspect and implement the first milestone. Check the reported tests and launch command. Baseline commands (existing package scripts; Claude may update): `npm.cmd install` (or `npm.cmd ci` if a lockfile exists), `npm.cmd run check`, `npm.cmd start`. If the app fails to start, give Claude the exact terminal error. Use demo data only.
5. For the next milestone, send: "Read CLAUDE.md and the master spec and current feature matrix/status. Resume the next incomplete milestone. Implement, test, fix regressions and leave the desktop application runnable. Report results and launch command."
6. When all mandatory features and QA gates are complete, ask Claude to build and validate the Windows installer. Existing baseline command: `npm.cmd run build:win`, expected output `dist\` (verify actual path). Test install/upgrade/uninstall on a Windows test system. An unsigned executable can cause SmartScreen warnings; document signing rather than disabling safeguards.
7. Later configure AI using the application's settings and documented authenticated backend (OpenAI key stored server-side; never in Claude chat, source or Git). Use synthetic data only until authorization and approved retention requirements for children's personal data are verified. API billing separate from ChatGPT; n8n optional.
